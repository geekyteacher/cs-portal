## Today you will

Playtest a partner's maze, record what happens, and use feedback to improve
your own game.

## Starter: fun or frustrating?

What makes a game enjoyable to play? Think about controls, instructions,
difficulty, and how clearly the game shows what to do.

## Playtest a partner's game

Ask before opening or playing your partner's project. Try the test cases
below and record what happens.

| Test | What to try | What happened? |
| --- | --- | --- |
| Controls | Try each arrow key | |
| Walls | Move into each side of a wall | |
| Collectibles | Collect one item, then try it again | |
| Score | Collect three items and check the score | |
| Enemy | Touch the patrol enemy | |
| Win rule | Try the exit with too few items, then enough items | |
| Restart | Click the green flag again | |

Give feedback that is kind and specific. For example: “The player moved
through the top wall when I pressed up” is more useful than “It is broken.”

## Improve your game

Choose one issue or suggestion. Make a change, then repeat the test that
showed the issue. Record the result:

| What I changed | Test I repeated | Did it improve? |
| --- | --- | --- |
| | | |

## Challenge choices

If your core game works and has been tested, choose a new feature:

- Add a patrol enemy using the [Loops and Patrol Enemies
  lesson](/year5/programming/scratch-game-mechanics/lesson-1-loops-and-patrol-enemies).
- Add lives or a second patrol enemy.
- Add a second level that is more difficult.
- Add a restart button and a clear instruction screen.
- Balance the challenge by changing movement speed, item positions, or the
  number of items needed.
- Add sound effects or extra player costumes.

Add one feature at a time and test it before adding another.

## Exit check

What was one test result that helped you decide what to improve?
