## Learn

### What is an Algorithm?

An algorithm is a set of step-by-step instructions used to solve a problem or complete a task.

Examples include:

- Following a recipe.
- Using directions to reach a destination.
- Calculating the area of a rectangle.
- Logging into a computer system.

### What is Sequence?

Sequence means instructions are carried out in the order they are written.

Changing the order of instructions may change the result.

Consider these instructions:

```text
1. Put cereal in a bowl.
2. Add milk.
3. Eat breakfast.
```

The order matters.

### Pseudocode Example

```pseudocode
name ← "Simon"
OUTPUT name
```

The value `"Simon"` is stored and then displayed.

What happens if the instructions are swapped?

```pseudocode

```

Discuss why this might cause a problem.

## Teacher Notes

### Common Misconceptions

- An algorithm must be written in a programming language.
- Pseudocode must follow exact syntax rules.
- Instructions can be performed in any order.

### Support

Students may benefit from:

- Real-world examples such as recipes.
- Physically sequencing instruction cards.
- Trace tables with a single variable.

### Stretch

Ask students to:

- Write multiple solutions to the same problem.
- Compare pseudocode and Python.
- Design an algorithm for a simple school-based task.
