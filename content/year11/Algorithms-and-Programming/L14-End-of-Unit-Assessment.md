## Assessment Conditions

- Complete all tasks independently under formal assessment conditions.
- Use official CAIE pseudocode conventions throughout.
- Show all workings in trace tables.
- Clearly label any assumptions made in longer-design questions.
- Read each question carefully before writing your answer.

---

## Section A: Trace and Debug

Given an algorithm containing an iteration loop and a decision statement:

### Task 1: Trace Table

Complete the trace table by tracking:

- `Counter`
- `Value`
- Condition results
- `Total`

Show every change of value as the algorithm executes.

### Task 2: Algorithm Analysis

A programmer changes a comparison operator:

```pseudocode
>
```

to:

```pseudocode
>=
```

Explain:

1. Which additional values will satisfy the condition.
2. How the output of the algorithm changes.
3. Why boundary values are important when testing this type of change.

---

## Section B: Standard Methods

Use the following array:

```text
[14, 5, 9, 5, 12]
```

### Task 1: Minimum and Maximum

Determine:

- The minimum value.
- The maximum value.

### Task 2: Average

Calculate the average of the values.

Show all working.

### Task 3: Counting Matches

Write CAIE pseudocode that counts how many times a target value appears in the array.

Your solution should:

- Accept a search value.
- Traverse the array.
- Output the final count.

---

## Section C: Validation & Verification

### Task 1: Test Data Classification

A program accepts quantities in the range:

```text
1 to 20 inclusive
```

Classify each test value as:

- Normal
- Abnormal
- Extreme
- Boundary

Explain your reasoning.

### Task 2: Verification

Describe one verification method.

For your chosen method:

1. Explain how it works.
2. State what type of error it helps detect.
3. Explain one limitation of the method.

---

## Section D: Algorithm Design

### Sports Club Scenario

A sports club needs a system to store player names and scores.

Design an algorithm that:

1. Stores player names in an array.
2. Stores player scores in an array.
3. Counts how many players achieved a score of **10 or more**.
4. Finds the highest score.
5. Identifies the player who achieved the highest score.
6. Calculates the average score.
7. Outputs all required results clearly.

Your solution should use appropriate variables, arrays, loops, and decision statements.

---

## Section E: Subprograms & Files

### Task 1: Function

Write a function that:

- Accepts two numerical parameters.
- Returns their sum.

Demonstrate how the function would be called from the main program.

### Task 2: File Handling

Write CAIE pseudocode that:

1. Opens a text file for reading.
2. Reads a line from the file.
3. Stores the line in a variable.
4. Closes the file.

Use the commands:

- `OPENFILE`
- `READFILE`
- `CLOSEFILE`

## Success Criteria

To achieve full marks, students should demonstrate:

- Accurate trace-table completion.
- Correct use of standard algorithms.
- Appropriate test data selection.
- Understanding of validation and verification.
- Well-structured pseudocode.
- Correct use of arrays, loops, decisions, functions, and file handling.
- Clear and logical algorithm design.

## Extension Challenge

After completing the assessment, review one of your answers and explain:

1. How it could be improved.
2. Which test data you would use to verify it works correctly.
3. Which boundary cases are most likely to reveal bugs.

This mirrors the evaluation stage of real software development and helps prepare for Paper 2 examination questions.
