## Learning goals

- Explain what USB is used for.
- Describe benefits of the USB interface.
- Describe drawbacks or limitations of using USB.
- Evaluate whether USB is suitable for a given situation.

## Quick start

List three devices you have seen connected to a computer using USB. What
makes one type of connection useful for lots of different devices?

## What is USB?

**USB** stands for **Universal Serial Bus**. It is a widely used interface
for connecting peripheral devices to a computer and transferring data. USB
sends data serially: bits travel one after another between the computer and
the connected device.

## Benefits of USB

- **Widely used standard:** many computers and peripherals support USB, making
  it convenient to connect different devices.
- **Plug and play:** a compatible device can often be connected and detected
  without the user having to configure the connection manually.
- **Power and data:** a USB connection can provide power as well as transfer
  data for suitable devices.
- **Hot-swappable:** compatible devices can usually be connected or
  disconnected while the computer is running.

## Drawbacks and limitations

- **Cable length is limited:** USB is intended for connecting nearby
  peripherals, not devices over long distances.
- **Compatibility can vary:** connectors and capabilities differ between USB
  versions, so the cable, port, and device must be compatible.
- **Power is limited:** some devices need more power than a USB port or hub
  can provide and may require a separate power source.

## Worked example

A school wants to connect a keyboard, mouse, and webcam to a desktop
computer.

USB is suitable because it is a common interface for peripherals, and
compatible devices can usually be connected while the computer is running.
However, the school should check that the computer has enough suitable ports
and that any hub can provide enough power for the connected devices.

## Practice

### 1. Benefits and drawbacks

For each statement, decide whether it describes a benefit or a limitation of
USB:

1. A compatible device can be detected when it is connected.
2. A device may need a separate power supply.
3. The same interface is supported by many kinds of peripherals.
4. The connection is not intended for very long cable distances.

### 2. Explain your choices

A student wants to connect a printer to a computer in the next room using a
long USB cable.

1. State one reason USB may not be suitable for this setup.
2. Suggest what the student should check before choosing a cable or hub.

### 3. Exam-style response

State two benefits and one limitation of using USB to connect a peripheral
to a computer. Explain each point.

## Exit check
