## Unit overview

This unit is planned for **15 hours**, taught as ten 90-minute double
periods. The pages cover the three syllabus sections: CPU architecture,
assembly language, and bit manipulation, followed by a mixed checkpoint.

The content and instruction examples below follow the CAIE 9618 syllabus
for examinations in 2027–2029. Use the [syllabus
checklist](#syllabus-checklist) to track teaching and practice.

## Teaching pages

1. [CPU architecture](./cpu-architecture) — the Von Neumann model, registers,
   buses, the fetch-execute cycle, interrupts, peripherals, and performance.
2. [Assembly language](./assembly-language) — the two-pass assembler,
   instruction groups, addressing modes, tracing, and writing routines.
3. [Bit manipulation](./bit-manipulation) — logical operations, logical,
   arithmetic and cyclic shifts, and masks.
4. [Mixed practice and checkpoint](./checkpoint) — retrieve and apply the
   unit content in exam-style questions.

## Suggested ten-double sequence

| Double | Focus |
| ---: | --- |
| 1 | Von Neumann architecture, stored-program concept, CPU components, and registers. |
| 2 | Buses, register-transfer notation, and a worked fetch-execute cycle trace. |
| 3 | Interrupt causes and handling; peripheral ports; processor performance. |
| 4 | Consolidate CPU operation with tracing, diagrams, and exam-style explanations. |
| 5 | Two-pass assembly, instruction groups, operands, and addressing modes. |
| 6 | Trace routines, including memory, comparisons, and conditional jumps. |
| 7 | Write and debug short routines, including input, output, and labels. |
| 8 | AND, OR, and XOR; binary shifts and their effects. |
| 9 | Logical, arithmetic, and cyclic shifts; use masks to test and set bits. |
| 10 | Mixed exam practice, checkpoint, feedback, and targeted review. |

This is a pacing guide, not a requirement to finish every activity in one
period. Use checkpoint results to decide whether to revisit a concept.

## Syllabus checklist

Use the current CAIE 9618 syllabus as the authority. Mark each objective
after it has been taught and practised.

- [ ] Explain the Von Neumann model and the stored-program concept.
- [ ] Explain the purpose of the ALU, CU, system clock, IAS, and general- and
  special-purpose registers.
- [ ] Explain how the address, data, and control buses transfer information.
- [ ] Use register-transfer notation to describe and trace the fetch-execute
  cycle.
- [ ] Explain interrupt causes and applications, the role of an ISR, when
  interrupts are checked, and how they are handled.
- [ ] Explain how USB, HDMI, and VGA ports connect peripheral devices.
- [ ] Explain how processor type, core count, bus width, clock speed, and
  cache memory affect performance.
- [ ] Describe the stages of a two-pass assembler.
- [ ] Read, trace, write, and debug assembly using the syllabus instruction
  set and immediate, direct, indirect, indexed, and relative addressing.
- [ ] Apply AND, OR, and XOR; perform logical, arithmetic, and cyclic shifts.
- [ ] Use bit masks to test and set bits.
- [ ] Answer exam-style questions with accurate technical terminology.

## How to use this unit

- Use the teaching pages for explanations, worked examples, and class
  practice. Work through the examples on paper before checking your trace.
- Complete the homework set by your teacher; it should prepare for or
  reinforce the next double.
- Use the final checkpoint to identify topics that need another explanation
  or practice.
- Keep any class notes and assessment answers in the location your teacher
  specifies.
