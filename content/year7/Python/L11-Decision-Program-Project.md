## Today you will

Complete your decision program independently, test its rules, and explain
how your conditions work.

## Quick check

1. What three values should you test around a boundary?
2. What happens after Python finds the first true condition in an
   `if`/`elif`/`else` structure?
3. What does `else` represent?

## Project task

Continue the program you planned in [Decision Program Project: Plan and
Start](/year7/python/l10-decision-program-project-plan). Complete your chosen
brief and make sure it follows the rule table exactly.

You are working independently. You may use the notes and worked examples
from previous lessons, but write and explain your own program.

## Success criteria

Your program should:

- ask the user to enter the required whole number;
- convert the answer using `int()`;
- store the number in a clearly named variable;
- use `if`, `elif`, and `else` to produce the outcomes from the brief;
- use conditions in an order that gives the correct outcome;
- display a clear message for every outcome; and
- run and pass the tests in your test table.

## Explain your program

When you finish, be ready to explain:

1. what value your program asks the user to enter;
2. why you used `int()`;
3. what each condition checks;
4. why the conditions are in that order; and
5. one change you made after testing.

## Extension

If the core program works and all boundary tests pass, add a second numeric
condition using `and` or `or`. Explain what the combined condition checks
and test both sides of its boundary. This is optional; do not add it before
the required program works.
